## 一、软件概述

### 1.1 软件名称
TruthLens 真视镜 V1.0.0

### 1.2 软件用途
TruthLens 真视镜是一款专业的AI内容检测工具，采用多模型联合分析技术，帮助用户快速识别文本、图片、文档等内容是否由人工智能（AI）生成。

### 1.3 主要功能
- **文本检测**：识别ChatGPT、Claude、文心一言等AI生成的文章、论文、简历等文本
- **图片识别**：辨别Midjourney、Stable Diffusion、DALL-E等AI绘图工具生成的图像
- **文档分析**：支持PDF、Word文档批量检测，自动提取文本内容进行分析
- **详细报告**：多维度分析结果，可视化展示AI生成概率

### 1.4 运行环境
- **Web端**：Chrome 80+、Firefox 75+、Safari 13+、Edge 80+
- **移动端**：Android 8.0+、iOS 13+
- **PWA支持**：可安装为桌面/移动应用，支持离线使用

## 三、功能说明

### 3.1 文本检测功能

#### 3.1.1 功能描述
用户可以在文本输入框中粘贴或输入需要检测的文本内容，系统将分析文本的语言学特征，判断是否为AI生成。

#### 3.1.2 使用流程
1. 进入应用首页
2. 选择"文本检测"标签
3. 在文本框中粘贴待检测内容
4. 点击"开始检测"按钮
5. 查看检测结果和详细分析

#### 3.1.3 检测维度
- **词汇丰富度**：分析词汇多样性和重复度
- **句式复杂度**：检测句子结构复杂度
- **语义连贯性**：评估上下文逻辑连贯性
- **逻辑结构**：分析段落组织逻辑

### 3.2 图片检测功能

#### 3.2.1 功能描述
支持上传图片文件，通过图像特征分析识别是否为AI生成图像。

#### 3.2.2 支持格式
- JPG/JPEG
- PNG
- WebP
- 最大文件大小：10MB

#### 3.2.3 使用流程
1. 选择"图片检测"标签
2. 点击上传区域或拖拽图片
3. 等待图片上传完成
4. 点击"开始检测"
5. 查看检测结果

### 3.3 文档检测功能

#### 3.3.1 功能描述
支持上传PDF、Word文档，自动提取文档内容进行检测分析。

#### 3.3.2 支持格式
- PDF
- DOC/DOCX
- 最大文件大小：50MB

#### 3.3.3 使用流程
1. 选择"文档检测"标签
2. 上传文档文件
3. 系统自动提取文本内容
4. 执行检测分析
5. 生成检测报告

### 3.4 检测结果展示

#### 3.4.1 结果页面
- **AI生成概率**：百分比形式展示
- **风险等级**：低/中/高/极高
- **置信度**：检测结果的可靠程度
- **详细分析**：多维度分析数据

#### 3.4.2 结果解读
- **0-30%**：极可能是人类创作
- **30-70%**：可能包含AI生成内容
- **70-100%**：高度疑似AI生成

## 四、技术特点

### 4.1 多模型联合分析
采用多个检测模型并行计算，综合各模型结果，提高检测准确率。

### 4.2 本地处理优先
核心检测功能优先在本地执行，保护用户隐私，减少网络传输。

### 4.3 PWA技术支持
- **离线访问**：Service Worker缓存核心资源
- **安装应用**：可添加到主屏幕，像原生应用一样使用
- **后台同步**：支持后台数据同步

### 4.4 响应式设计
适配各种屏幕尺寸，从手机到桌面端都能获得良好体验。
